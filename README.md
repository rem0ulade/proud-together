# Proud Together e.V.

Moderne, barrierearme Website für den geplanten gemeinnützigen Verein Proud Together e.V. Die Seite stellt Mission, Arbeitsbereiche, das digitale Projekt „Wo-stehst-du“ und Möglichkeiten zum Mitmachen vor.

## Wichtiger Hinweis vor dem offiziellen Start

Der Verein befindet sich in Gründung. Die klar gekennzeichneten Platzhalter in Impressum und Datenschutz müssen mit den echten Vereinsdaten ergänzt und rechtlich geprüft werden. Spenden werden erst nach Vereinsgründung und Einrichtung eines Vereinskontos aktiviert.

## Entwicklung

```bash
npm install
npm run dev
```

Die Veröffentlichung auf GitHub Pages erfolgt automatisch über den Workflow in `.github/workflows/pages.yml`.
